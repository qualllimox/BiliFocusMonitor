# B站自律监督 (BiliFocusMonitor)

专为 **vivo V2430A (vivo S20 Pro / OriginOS `PD2430B_A_16.1.12.0` / Android 14+)** 适配开发的哔哩哔哩使用时长监控与防沉迷应用。

## 核心功能
1. **精准读取B站使用时长**：通过系统 `UsageStatsManager.queryEvents()` 从手机「应用使用详情」读取今日 `tv.danmaku.bili`（含国际版/HD版）的前台使用总时长。
2. **可调节每日阈值**：支持 `0.5h ~ 6.0h` 滑动调节及快捷预设（`0.5h / 1.0h / 1.5h / 2.0h`）。
3. **超限自动关闭B站并弹窗提醒**：
   - 达到阈值时，通过无障碍服务 (`AccessibilityService`) 自动执行返回桌面操作，退出 B站；
   - 弹出提醒对话框：`今日bilibili使用时长已达（阈值）h,快去复习！`。
4. **简易实用附加功能**：
   - 提前 5 分钟通知预警；
   - 超限后严格拦截模式（重新打开 B站 立即退出）；
   - 近 7 天 B站 使用时长统计与日均计算；
   - 临时延时 +15 分钟应急按钮；
   - 一键跳转 vivo / OriginOS 权限与后台保活设置。

## 编译与安装步骤
1. 使用 **Android Studio**（Ladybug / 2024.2 或更新版本，JDK 17）打开本目录。
2. 等待 Gradle 同步完成（需联网下载依赖）。
3. 手机开启「开发者选项 → USB 调试」后连接电脑，点击 **Run ▶** 即可直接安装到 vivo V2430A 上；或点击 `Build -> Build Bundle(s) / APK(s) -> Build APK(s)` 生成 `.apk` 文件传输到手机安装。

## 首次使用权限配置（V2430A OriginOS）
打开 App 后，按首页底部引导依次开启：
1. **使用情况访问权限**（用于读取 B站 使用时长）
2. **无障碍服务**（用于达标后自动退出 B站）
3. **悬浮窗权限**（用于后台弹出提醒框）
4. **忽略电池优化** + i管家中开启「自启动」并在多任务中「锁定」本应用卡片。
